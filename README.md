# CodeGraph-MCP (Codename: *Antidote*)
> **The Structural AST, Semantic Reuse, and Integrity Engine for AI Coding Agents**

`CodeGraph-MCP` is an ultra-fast, local-first engine written in Rust that provides **Tree-sitter AST structural navigation**, **semantic reuse interception (Dense + BM25)**, and an **out-of-process Language Server (LSP) worker** exposed via the Model Context Protocol (MCP).

Designed for **Claude Code, Antigravity, Cursor, and Windsurf**.

See [PRD.md](./PRD.md) for complete architectural specifications.
